# TQS v0.9.0 — Cockpit / Metric Lake

Release intent: make one instrument the center of analysis and connect visual context to reproducible local data.

Highlights:
- instrument-first TQS Cockpit replaces the legacy v0.7 dashboard shell;
- synchronized candles + volume + live OI/funding + historical Metric Lake panels;
- cross-venue economic context with venue deviations;
- public Hyperliquid fill markers/events where timestamps are observed;
- Binance funding/OI/basis historical adapters;
- MOEX FUTOI physical/legal participant metrics with delay provenance;
- Bybit historical OI/funding adapter and autonomous MAX metric planner;
- Data Lake reports candle + metric storage separately;
- missing data is visible and can trigger bounded backfill;
- MAX distinguishes candle history from derivative metric work.

Verification remains CI + local runtime evidence. Browser/visual acceptance still requires local screenshot/interaction after owner updates the Windows runtime.
