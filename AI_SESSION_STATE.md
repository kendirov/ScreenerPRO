---

## Текущая задача

Финальная полировка режима **«Модель стакана»** — учебный экран для урока и записи видео.

---

## Что сделано (2026-05-19, полировка «Модель стакана»)

### Упрощённый UI

- Тёмный самодостаточный блок: баннер **«Учебная симуляция · не реальные котировки MOEX»**, заголовок **«Биржевой стакан»**
- Центральная схема: кластера | лента | стакан + подписи Ask / Spread / Bid
- Одна панель управления (без 80 уровней, MM, инспекторов, графика, сценариев DOM)
- Выпадающий список **сценариев** вместо ряда из 7 кнопок

### Управление (оставлено)

| Кнопка | Действие |
|--------|----------|
| Сценарий | select, 7 учебных сцен |
| Пуск / Пауза | авто-сцена (рыночная покупка/продажа, айсберг) |
| Шаг | один шаг сцены |
| Рыночная покупка / продажа | одна сделка + кластер |
| Очистить | сброс ленты |
| 10K / 20K / 50K | масштаб заливки баров |
| Презентационный вид | крупные подписи, меньше деталей |

### Справка

- Раскрываемый блок **«Что здесь показано»** (4 пункта из ТЗ)
- В обычном виде — блоки «Что видим / Что это значит / Куда смотреть»
- В презентации — только крупная подпись сценария + легенда внизу

### Страница Lab

- В режиме «Модель стакана» pills: **Учебная симуляция** + название вида (без pill режима UI урок/рабочий)

### Не затронуто

- **Привод**, **Стакан крупно**, **Учебный**, **Мультиокно**
