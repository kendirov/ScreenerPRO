# Минимализм цифр — стандарт UI ScreenerPRO

Документ для продуктовых решений, ChatGPT и Cursor. Описывает **как показывать числа** в интерфейсе, не меняя модель данных и API.

Связанные файлы: `PRODUCT_VISION.md`, `PROJECT_CONTEXT.md`, `frontend/components/ui/metrics-minimalism.tsx`.

---

## Зачем

Трейдеру нужен **быстрый скан**: где деньги, сделки, диапазон, активность. Лишние цифры на экране создают шум и замедляют решение. Данные в модели остаются полными; меняется только **слой отображения**.

---

## 10 правил

| # | Правило | На практике |
|---|---------|-------------|
| 1 | **На карточке — максимум 2–3 числа** | Тикер + % + одна метрика (оборот или диапазон). Остальное — tooltip / inspector. |
| 2 | **В таблице — 5–7 колонок по умолчанию** | Compact view без «расширенных» колонок на первом экране. Детали — expanded row / inspector. |
| 3 | **Вторичные метрики — tooltip / inspector / accordion** | Точный оборот, средняя сделка, к вчера, источник, время обновления. |
| 4 | **Нули не показывать, если поле недоступно** | `null`, `0` сделок, пустой оборот → «—» или скрыть поле; не «0» на поверхности. |
| 5 | **Debug-подписи скрывать** | Нет `IN_PLAY`, `debug`, технических id на UI. Только пользовательские статусы на русском. |
| 6 | **Графики только реальные** | Свечи / история из MOEX или БД. Без декоративных синусоид. Empty: «история недоступна». |
| 7 | **Empty state объясняет, чего не хватает** | Не «Нет данных», а «Активных бумаг нет — ждём рост оборота или сделок». |
| 8 | **Статус данных обязателен при partial / fallback** | `DataStatusBadge`: MOEX ISS · резерв · частично · загрузка. |
| 9 | **Тикер важнее названия** | Название — tooltip, inspector, карточка тикера. На поверхности — тикер. |
| 10 | **Причина попадания важнее лишней цифры** | Chips: оборот, сделки, диапазон, импульс. Не дублировать score на карточке. |

## Компоненты (единая точка)

Использовать из `frontend/components/ui/metrics-minimalism.tsx`:

| Комponent | Назначение |
|-----------|------------|
| `CompactMetric` | Короткое число на поверхности; полное — в tooltip при hover. |
| `MetricTooltip` / `MetricTooltipPanel` | Блок вторичных полей (label + value). |
| `StatusChip` | Статус инструмента или режима (lab-status-chip). |
| `DataStatusBadge` | Источник / качество данных (MOEX, fallback, partial). |

Не дублировать локальные `RadarTooltipRow`, `DetailRow` — импортировать общие примитивы.
