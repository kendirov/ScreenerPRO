# AI development index

Минимальная карта контекста для Chat-first разработки.

- `../../AGENTS.md` — главный execution router.
- `CURRENT_STATE.md` — freshest resume point.
- `VERIFICATION.md` — FAST/FULL/LIVE/SECURITY и VERIFIED PASS.
- `../exec-plans/active/` — активные bounded plans.
- `../exec-plans/completed/` — законченные планы/решения, читать только при необходимости.
- `../adr/` — архитектурные решения.
- `../../tqs-intelligence/AGENTS.md` — TQS product-specific router.

Принцип progressive disclosure: сначала эта карта и CURRENT_STATE, затем только документы/код, которые materially влияют на текущую задачу.
