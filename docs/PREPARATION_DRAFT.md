# PREPARATION_DRAFT — «Подготовка»

Маршрут: **`/lab/preparation`**

Статус: **черновик · ЛАБ · премаркет-пульт (2026-05-25)**

---

## Цель страницы

**Компактный премаркет-пульт** перед утренним / недельным брифингом по MOEX.

Меньше шума на первом экране — больше решения: что сказать, что открыть, в каком порядке.

---

## Первый экран (4 зоны + инфляция)

| Зона | Содержимое |
|------|------------|
| **1. Фокус брифинга** | До 8 пунктов (scoring без AI): события · драйверы · инструменты · причина · что открыть · «Собрать порядок эфира» |
| **2. Ближайшие события** | Timeline до 6: время · событие · источник (Smart-Lab / **ручной**) · статус драйвера |
| **3. Инструменты** | До 6 фокус-строк: тикер · 1д/5д (реальные свечи) · оборот · статус данных |
| **4. Порядок эфира** | Контекст → События → Внешний фон → Товары → Валюта → Индекс → Фишки → В игре → Итог (+ инфляция/ставка) |
| **Недельная инфляция** | KPI из shared storage или «данные не загружены» + «Добавить данные» → `/lab/weekly-inflation` |

Переключатель источника событий (Ручные / Smart-Lab / Все) — над сеткой зон 2–4.

---

## Data honesty

| Правило | Реализация |
|---------|------------|
| Нет фейковых котировок | MOEX ISS + candles API; external = «внешний источник не подключён» |
| Нет -100% без свечи | `computeChangePct` + `computePreparationChanges` отсекают abs ≥ 99.95% |
| Нет декоративных графиков | Sparkline/history только при реальных свечах |
| Ручной источник | Бейдж «ручной» на событиях не из Smart-Lab |
| Empty states | Честные тексты (см. ниже) |

---

## Empty states

| Ситуация | Текст |
|----------|-------|
| Нет свечей | «Данных сегодня нет» / «Последняя свеча DD.MM» |
| Smart-Lab недоступен | «Smart-Lab недоступен — добавьте события вручную» |
| Фокус пуст | «Недостаточно данных. Используем ручной список подготовки.» |
| Инфляция | «данные не загружены» + кнопка «Добавить данные» |
| Внешние инструменты | «внешний источник не подключён» |
