# Привод-симулятор

Маршрут: **`/lab/orderflow-simulator`** · sidebar → **Черновики** → **Привод-симулятор**

Документ описывает первую версию (v1) учебного черновика в зоне LAB.

---

## Что это

**Привод-симулятор** — интерактивная **учебная модель** микроструктуры рынка: стакан заявок (price ladder), лента сделок (пузыри + Time & Sales), footprint-кластера и свечной график с объёмами.

Инструмент создан для **разбора ситуаций на уроках** и **демонстрации в видео**, а не для торговли.

По умолчанию условный инструмент **GAZP**; в режиме **Мультиокно** — набор **demo**-тикеров (GAZP, SI, CNY, EU, SBER, VTBR). Все цены **синтетические**, не live MOEX.

---

## Что показывает

| Элемент | Смысл в симуляции |
|---------|-------------------|
| **Лимитная заявка** | Добавляет объём в bid или ask на выбранной цене |
| **Рыночная заявка** | Покупка забирает ask; продажа бьёт по bid |
| **Bid / Ask** | Зоны лимитной ликвидности в стакане |
| **Спред** | Разрыв между лучшим bid и ask (визуально в стакане) |
| **Крупная плотность** | Янтарная подсветка и метка «крупн.» на уровне |
| **Айсберг** | Видимый объём восстанавливается из скрытого резерва |
| **Абсорбция** | Много агрессивных продаж при ограниченном падении цены |
| **Отскок** | Продажи у уровня bid, затем покупки от зоны |
| **Пробой** | Исчерпание плотности и ускорение ниже уровня |

Все принты, свечи и кластера **генерируются движком симуляции** в браузере.

## Виды и режимы интерфейса

### Вид (layout)

| Вид | Назначение |
|-----|------------|
| **Привод** | Плотный терминальный canvas: график + стакан с пузырями сделок слева + footprint (отдельной пустой колонки ленты нет) |
| **Стакан крупно** | DOM и лента на весь экран; график свёрнут в `<details>`; инспектор уровня справа — **вид по умолчанию** при входе в Lab |
| **Учебный** | Классическая раскладка с полной панелью управления |
| **Модель стакана** | Упрощённая учебная схема: 40 уровней, лента кругами (справа→налево), кластера; **без графика** и без движка DOM 80 уровней — для урока и видео |
| **Мультиокно** | 6 demo-плиток; клик → открыть инструмент в «Привод» |

### Режим UI

| Режим | Назначение |
|-------|------------|
| **Рабочий** | Полный набор панелей и ручного управления |
| **Урок** | Сценарии, журнал шагов, аннотации, подсказки |
| **Презентация** | Крупная цена, минимум кнопок, подсказка цепочки урока — для записи экрана |

На экране всегда явная пометка **«Симуляция»** / **demo**.

## Какие сценарии есть

| Сценарий | Цель урока |
|----------|------------|
| **Спокойный рынок** | Увидеть фон: мелкие сделки без доминирующей плотности |
| **Отскок от bid** | Плотность bid принимает продажи; уровень держат; возможен отскок |
| **Пробой bid** | Плотность съедают; агрессивные продажи ниже уровня |
| **Ask-плотность** | Покупки бьют в ask; отбой и откат |
| **Айсберг** | Малый видимый bid восстанавливается — модель скрытого объёма |
| **Абсорбция** | Много продаж, цена не уходит далеко; красные кластера; восстановление bid |

В **Мультиокно** дополнительно: учебная сцена **«Рынок под давлением»** (синхронные шаги по нескольким demo-инструментам; не модель реальной корреляции MOEX).

Сценарии **не гарантируют** такое же поведение на реальном рынке.

## Как сделать урок

Шаблон пошагового разбора для режима **Урок** или **Презентация**:

1. **Выберите сценарий** — в панели сценариев (отскок, пробой, айсберг и т.д.).
2. **Запустите пошагово** — «Пуск» или клавиша → (Space — пауза/пуск).
3. **Покажите плотность** — в стакане: янтарная зона, метка «крупн.» или айсберг «ice».
4. **Покажите рыночные сделки** — кнопки покупка/продажа или шаг сценария.
5. **Покажите, как они попали в ленту** — зелёные/красные пузыри, размер от объёма; при необходимости раскройте список Time & Sales.
6. **Покажите кластера** — переключите режим footprint (объём, дельта, имбаланс); отметьте абсорбцию внизу панели.
7. **Покажите свечу** — как изменилась последняя свеча и объём под графиком.
8. **Объясните итог** — удержали уровень (плотность приняла удары) или пробили (ликвидность съедена, цена ушла дальше).

В **Презентации** сверху отображается подсказка цепочки: лимитка → сделка → лента → кластер → свеча.

## Ручное управление

- **Рыночная покупка / продажа** — проход по стакану, обновление ленты, кластеров и свечи
- **Bid / Ask-плотность** — лимитный объём на цене
- **Пуск / Пауза / Шаг / Сброс**
- Таймфрейм графика: **1м** или **5м**
- Сложение тиков в ленте: **50 / 100 / 250 мс** (скрыто в презентации)

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| Space | Пуск / Пауза |
| → | Следующий шаг |
| R | Сброс |
| B | Рыночная покупка |
| S | Рыночная продажа |
| D | Bid-плотность |
| A | Ask-плотность |

## Что важно помнить

- Это **симуляция**, не реальные котировки и не подключение к бирже.
- Данные **не следует** использовать как рыночный сигнал.
- Тексты и сценарии — **обучение микроструктуре**, не рекомендации «покупать/продавать».
- Раздел находится в **Черновиках (LAB)** и может меняться без версионирования API.
- Визуал **не копирует** чужие торговые терминалы — собственный учебный стиль ScreenerPRO.

## Ключевая композиция привода

Режим **Привод** — учебный скальперский терминал: график слева, справа **узкий стакан** (~168–200px) с **кругами сделок** у левого края DOM (не отдельная пустая колонка), снизу footprint.

```
┌──────────────────────────┬─────────────────┐
│  График GAZP             │ ○○  объём│цена │
│  свечи + объём           │     стакан      │
├──────────────────────────┴─────────────────┤
│           Кластера / footprint              │
└────────────────────────────────────────────┘
```

| Зона | Что показывает | Роль в уроке |
|------|----------------|--------------|
| **График** (слева) | Свечи 1м/5м, объёмы снизу, линия текущей цены | **Результат** движения — куда ушла цена после сделок |
| **Круги у стакана** | Зелёный = покупка, красный = продажа, размер ≈ √ объёма, привязка к цене строки | **Исполнения** — что прошло по рынку в симуляции |
| **Стакан** (справа) | Ask сверху, bid снизу; **объём слева** (горизонтальный бар), **цена справа**; янтарь ≥10K; шкала баров 10K/20K/50K | **Лимитная ликвидность** — что стояло до удара |
| **Кластера** (снизу) | Footprint по ценам и временным бакетам | **Накопленный объём** — где прошла основная ликвидность |

### Дефолты DOM (Привод / Стакан крупно)

| Параметр | По умолчанию |
|----------|----------------|
| Вид при входе | **Стакан крупно** |
| Уровней в окне | 80 |
| Высота строки | 16 px (в «Стакан крупно» — 18 px) |
| Шкала бара | 20K (20 000 лотов = 100% ширины) |
| Профиль / плотности / круги / авто-центр | включены |
| Формат объёма | `500`, `1.5K`, `20K` |

Синтетический стакан при старте заполняет уровни лотами **300–25K** (тираж по tier + психо-уровни).

Учебные **сценарии** связывают все четыре зоны: шаг меняет стакан → появляются сделки в ленте → обновляются кластера → меняется свеча. Краткое объяснение показывается в режиме **Урок** / **Презентация**.

Цветовая логика (собственный стиль ScreenerPRO, не копия чужих терминалов):

- покупка / bid — зелёный;
- продажа / ask — красный;
- крупная плотность — янтарный;
- айсберг — фиолетовый / циан;
- текущая цена — бирюзовая линия;
- пометка симуляции — тонкий жёлтый акцент.

## Режим «Модель стакана» (учебная схема)

Отдельный вид **не использует** движок `orderflow-simulator-engine`, сценарии DOM «Привода» и график. Все данные — **учебная симуляция**, не MOEX.

### Управление (минимум)

| Элемент | Назначение |
|---------|------------|
| **Сценарий** (выпадающий список) | 7 учебных сцен (см. ниже) |
| **Пуск / Пауза** | Авто-сцена для анимированных сценариев |
| **Шаг** | Один шаг сцены (сделка / удар по стакану) |
| **Рыночная покупка / продажа** | Одна сделка в ленте + кластер + вспышка ask/bid |
| **Очистить** | Сброс ленты |
| **Заливка 10K / 20K / 50K** | Масштаб ширины баров объёма |
| **Презентационный вид** | Крупнее подписи, меньше «технической шелухи» |

Раскрываемый блок **«Что здесь показано»** — краткая справка для ученика.

### Сценарии модели стакана

| Сценарий | Содержание |
|----------|------------|
| Обычный стакан | Объёмы 300–2500, виден spread |
| Крупная заявка на покупку | Bid 20K ниже лучшего bid |
| Крупная заявка на продажу | Ask 20K выше лучшего ask |
| Рыночная покупка | Зелёные круги, −ask, +кластер |
| Рыночная продажа | Красные круги, −bid, +кластер |
| Спред | Подсветка зазора bid/ask |
| Айсберг простыми словами | Видимо 2K, проход ~10K, восстановление |

У каждого сценария: подпись + (в обычном виде) блоки **Что видим / Что это значит / Куда смотреть**.
